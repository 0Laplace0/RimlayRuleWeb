# RimlayRuleWeb

## 🛠️ Tech Stack

### 🎨 Frontend ( /FE )
* **Framework**: React
* **Language**: JavaScript (JSX)
* **Routing**: React Router DOM (`useLocation`)
* **Styling**: Tailwind CSS
* **HTTP Client**: Axios

### ⚙️ Backend ( /BE )
* **Server**: Node.js / Express
* **API Architecture**: RESTful API
* **Data Format**: JSON / Quill Delta
